YOUR FIRST STEPS

Learn by changing the code

  1. Type a message in the input.
  2. Open app.psc and find message.upper().
  3. Replace it with message[::-1] to reverse the text.
  4. Save, reload the page, and try again.

This is a learning prototype, not a browser-native HTML standard. The engine uses JavaScript internally to initialize Pyodide; application logic is written in Python.
