# Contributing to HTML6

Thanks for helping improve this experimental project. Contributions can include bug reports, clearer documentation, learning exercises, examples, accessibility improvements, and code.

## Before you start

1. Search existing issues to avoid duplicates.
2. For a large change, open an issue first to discuss the goal.
3. Keep pull requests focused and explain the user-visible impact.

## Development

1. Fork the repository and clone your fork.
2. Start a local server with `python -m http.server 8000`.
3. Open `http://localhost:8000`.
4. Test the demo with empty input, ordinary text, non-English characters, and long input.
5. Check the browser console for errors.

## Pull request checklist

- [ ] The change has a clear purpose.
- [ ] Documentation is updated when behavior changes.
- [ ] The demo still loads using HTTP.
- [ ] No secrets, credentials, or private data were added.
- [ ] Limitations and security implications are described honestly.

## Project principles

- Python-first application logic.
- Standard HTML and CSS for structure and presentation.
- Explainable code suitable for learners.
- Accessibility and browser compatibility.
- No claim that HTML6 is an official HTML standard.
